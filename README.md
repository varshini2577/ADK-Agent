# 📚 Assignment Bro - B.Tech Assignment Companion

An intelligent AI Agent built with **Google ADK** and **Gemini 2.0 Flash** that helps B.Tech students complete assignments.

### ✨ Features
- Writes full assignments for DBMS, OS, SE, JAVA etc.
- Adds real-world examples
- Generates ASCII diagrams for easy drawing
- Provides Viva Questions & Answers
- Runs on beautiful `adk web` UI

### 🚀 How to Run
```bash
cd my_first_agent
adk web
